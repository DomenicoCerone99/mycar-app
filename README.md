# MyCar

App gratuita per scadenze, rifornimenti, manutenzioni e parcheggio dell'auto. Senza account e senza pubblicità: i dati restano sul telefono.

**Scarica e istruzioni:** https://domenicocerone99.github.io/mycar-app/

Questa repo contiene solo la pagina di download e le versioni da scaricare (sezione *Releases*). Per domande o problemi apri una *Issue*.
