# MyCar

App **gratuita** per scadenze, rifornimenti, manutenzioni e parcheggio dell'auto: niente account, abbonamenti, acquisti o pubblicità. I dati restano sul telefono.

**Scarica e istruzioni:** https://domenicocerone99.github.io/mycar-app/

- Android: `MyCar.apk` nella sezione *Releases*.
- iPhone: `MyCar.ipa`, da installare con SideStore (istruzioni sulla pagina).
- [Privacy e condizioni d'uso](https://domenicocerone99.github.io/mycar-app/privacy.html)

Questa repo contiene solo la pagina di download e le versioni da scaricare; il codice dell'app non è pubblico. Per domande o problemi apri una *Issue*.
